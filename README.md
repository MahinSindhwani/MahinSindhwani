## Hi there, I'm Mahin👋

I’m a third-year Computer Science student at Memorial University of Newfoundland. I got into tech because of games, I’ve always been curious about how things work, and that curiosity led me to start building the things I used to wonder about. I taught myself to code as a kid and have been hooked ever since. I love how CS gives you the freedom to build anything you imagine. I’m a PAL leader for Calculus and Python programming, helping other students learn. I previously interned at Embrays Technologies, where I worked with an awesome dev team and learned a ton about collaboration and building software together.
